## ✨ What's new in v1.3.3 — Wallpaper Studio V2

Secreto TV Launcher **v1.3.3** introduces a richer cinematic home-screen experience, while keeping the lightweight Ocean Blue interface and D-pad-first navigation.

| Feature | What it does |
| --- | --- |
| 🎬 **19 cinematic wallpapers** | Four collections: **Cinematic, Winter, Morocco and Islamic** |
| 🔊 **Optional ambient sound** | Fireplace and selected rainy scenes include individually controlled audio; sound is **off by default** |
| 🌙 **Cinematic Fade** | An optional idle-time dimming experience that keeps the wallpaper visible |
| 🎛️ **Personalization** | Adjust the favorites-bar background opacity and customize your home screen |
| 🏠 **Home-screen continuity** | Improved wallpaper playback and transitions when returning Home |
| 📺 **Remote-first controls** | Designed for Android TV / Google TV navigation with the D-pad |
| 📥 **On-demand downloads** | Choose and download the wallpapers you want rather than bundling videos in the APK |

**Availability:** Android TV / Google TV running **Android 8.0+ (API 26+)**. Device compatibility and the ability to set a third-party default Home app depend on device firmware. Some media features require internet access for downloading wallpapers.

## 🧩 More features

- **Favorites and app management:** organize, search, hide and restore apps.
- **Move App:** long-press **OK**, select **Move App**, use the D-pad to reposition, then press **OK** to save or **Back** to cancel.
- **Quick settings:** convenient shortcuts to supported system settings.
- **Prayer times and Adhan:** city search, prayer-time controls and automatic Adhan playback.
- **Multilingual interface:** English, Arabic, French, Spanish and other supported translations; availability varies by release.
- **HDMI shortcuts:** available on certain compatible Xiaomi TVs.
- **About & Support:** in-app access to project information and voluntary support options.

> **Weather notice:** The weather feature is temporarily disabled. Prayer-city search, prayer times and automatic Adhan remain available. Open-Meteo Geocoding is used for prayer-city lookup; provider eligibility has not yet been confirmed.

## 📦 Download, install & update

**Current public release: [v1.3.3](https://github.com/mohamedlalah/SecretoTVLauncher/releases/tag/v1.3.3)**

1. Open **[Latest Releases](https://github.com/mohamedlalah/SecretoTVLauncher/releases/latest)** and download the **official signed APK** from the release assets.
2. Transfer it to your Android TV / Google TV device and install it using a trusted APK installer. Android may ask for permission to install from that source.
3. If upgrading from a previously installed **official** version, install **over the existing app without uninstalling** to preserve settings, favorites and app ordering. The package and signing certificate must match.
4. Select Secreto TV Launcher as your default Home app **if your device supports it**. Keep the original launcher available until you have tested the new setup.

**Security:** Download only from the official GitHub releases. Check the release notes and any published APK checksums before installation. The repository distributes APK releases and documentation; **it does not publish the modified app source code**.
